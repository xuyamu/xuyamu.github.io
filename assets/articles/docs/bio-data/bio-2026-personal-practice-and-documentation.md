　　我在2022年时，使用Aging.Ai检测了我在服用一系列抗衰老药前后生理年龄的变化，在此，我将我的数据公布供大家参考。
　　Aging.AI 是由人工智能药物研发与抗衰老生物科技公司 英矽智能（Insilico Medicine）（由 Alex Zhavoronkov 博士等人创立）开发的一系列基于深度学习的血液学“衰老生物钟”（Hematological Aging Clock），该网站后来因为公司业务调整而下线。
　　近期，我和朋友基于Healome 的开源模型 OpenAge开发了一个类似的网站，供有需要的生物黑客们使用：

　　https://agelensai.com/
